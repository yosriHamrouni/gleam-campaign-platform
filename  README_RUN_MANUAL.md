## 🚀 How to Run Gleam Manually

1️⃣ **Start MongoDB**
```bash
mongod --dbpath "C:\\Users\\yosri\\Downloads\\Brimind-VIBE\\generated\\Gleam\\data"
```

2️⃣ **In another terminal, run the project**
```bash
cd "C:\\Users\\yosri\\Downloads\\Brimind-VIBE\\generated\\Gleam"
npm run start
```

✅ When you see `MongoDB connected successfully to gleam`, open:
👉 http://localhost:3008/competitions/create

That’s all — no emoji or numbered commands are needed for execution.
